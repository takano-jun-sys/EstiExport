# EstiExport - AppSheet連携見積書作成システム

## 概要
AppSheetと連携してスプレッドシートのテンプレートから見積書を自動生成するGoogle Apps Script（GAS）プログラムです。

## 機能
- AppSheetからスプレッドシート経由でデータを受信
- テンプレートを元に見積書スプレッドシートを自動生成
- PDF形式でエクスポート
- 会社情報、税計算、明細行、備考欄などの詳細情報に対応

## システム構成

### 必要なスプレッドシート構成
1. **データシート** (`見積データ`) - AppSheetからのデータ入力用
2. **テンプレートシート** (`見積書テンプレート`) - 見積書のフォーマット
3. **設定シート** (`設定`) - 会社情報や設定値

### スクリプトファイル
- `Code.gs` - メインエントリーポイント
- `Config.gs` - 設定管理
- `QuoteGenerator.gs` - 見積書生成ロジック
- `PDFExporter.gs` - PDF出力処理
- `Setup.gs` - 初期セットアップ

## セットアップ手順

### 1. スプレッドシートの準備
1. 新しいGoogleスプレッドシートを作成
2. 以下のシートを作成：
   - `見積データ`
   - `見積書テンプレート`
   - `設定`

### 2. GASプロジェクトの設定
1. スプレッドシートから「拡張機能」→「Apps Script」を開く
2. このリポジトリの`.gs`ファイルをすべてコピー
3. `appsscript.json`の内容も設定

### 3. 初期設定の実行
1. GASエディタで`Setup.gs`の`setupSheets()`関数を実行
2. 必要な権限を承認
3. シートのヘッダーとテンプレートが自動作成されます

### 4. AppSheetとの連携
1. AppSheetで「見積データ」シートをデータソースとして接続
2. 見積入力フォームを作成
3. データを入力すると自動的に見積書が生成されます

## データシート列構成

| 列 | 項目名 | 説明 |
|---|---|---|
| A | 見積番号 | 自動採番 |
| B | 日付 | 見積日 |
| C | 顧客名 | お客様の会社名・氏名 |
| D | 郵便番号 | 顧客の郵便番号 |
| E | 住所 | 顧客の住所 |
| F | 電話番号 | 顧客の電話番号 |
| G | 件名 | 見積件名 |
| H | 明細JSON | 明細行のJSON配列 |
| I | 備考 | 備考欄 |
| J | 消費税率 | デフォルト10% |
| K | 有効期限 | 見積の有効期限 |
| L | ステータス | 作成済み/未作成 |
| M | スプレッドシートURL | 生成された見積書のURL |
| N | PDF URL | 生成されたPDFのURL |

## 明細JSONの形式
```json
[
  {
    "item": "商品名・サービス名",
    "quantity": 1,
    "unit": "式",
    "unitPrice": 100000,
    "amount": 100000,
    "note": "備考"
  }
]
```

## 使い方

### 手動実行
1. 「見積データ」シートにデータを入力
2. GASエディタで`processNewQuotes()`を実行

### 自動実行（推奨）
1. GASエディタで「トリガー」を設定
2. `processNewQuotes`関数を時間主導型（例：5分ごと）で実行

### トリガーの設定
```
関数: processNewQuotes
イベントのソース: 時間主導型
時間ベースのトリガー: 分タイマー（5分おき）
```

## カスタマイズ

### 会社情報の変更
「設定」シートで以下の項目を編集：
- 会社名
- 郵便番号
- 住所
- 電話番号
- FAX
- メールアドレス
- 振込先情報

### テンプレートのカスタマイズ
「見積書テンプレート」シートのデザインを自由に変更可能

## トラブルシューティング

### 見積書が生成されない
- 「見積データ」シートのステータスが「未作成」になっているか確認
- トリガーが正しく設定されているか確認
- 実行ログでエラーを確認

### PDFが生成されない
- スプレッドシートの共有設定を確認
- Google Driveの容量を確認
